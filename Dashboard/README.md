# Customer Support Dashboard

`Dashboard.png` is the dashboard deliverable. `dashboard-redesign.html` is an optional visual reference for the proposed layout; open it in a browser to view the responsive dashboard.

## Layout and measures

- KPI row: 50 total tickets, 19 resolved, 16 open, 3.7 day average resolution time, and 50% SLA achievement.
- Process improvement: AS-IS 5.68 days versus TO-BE 1.64 days, a 71% reduction (4.04 days faster).
- Operational overview: ticket status distribution and department ticket volume.
- Department performance: ticket count, average resolution time, SLA achievement, and priority for Operations, IT, Finance, and HR.
- Key finding: prioritize Operations, which handles 17 tickets, the largest department volume.

## Applying the layout in Power BI Desktop

Use the HTML page as a styling and layout reference. The final project deliverable is the static `Dashboard.png` preview, with five KPI cards at the top; an AS-IS/TO-BE comparison and improvement KPI; a status donut beside the department volume bar chart; and the department performance summary at the bottom.
